# Изображения

PNG-файлы сохранены как исходные экспорты из Figma. Одноимённые WebP-файлы
являются production-вариантами: максимальная ширина ограничена `1000 px`,
качество — `82`, прозрачность сохранена.

- `timeline-path-reference.png` — растровый референс, а `timeline-path.svg` —
  подготовленная для анимации векторная центральная линия.
- Закрытый и открытый конверты доступны только цельными изображениями, поэтому
  интро использует fallback с переходом между двумя композитами.
- Файлы `dress-beige.png`, `dress-black.png`, `dress-brown.png` и
  `dress-cream.png` содержат исходные JPEG-данные с неверным расширением;
  в приложении следует использовать их корректные WebP-варианты.
